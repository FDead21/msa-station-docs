# Invoices

The **Invoices** module lists all billing documents and lets you review, print, and track the payment status of each invoice.

Open it from the sidebar: **Report Data ➔ Invoices**.

![Invoices List](/img/tms_invoices_main.png)

---

## 📋 The Invoice List

The table shows every invoice with the following columns:

| Column | Meaning |
|---|---|
| **ID** | Invoice number/ID. |
| **Date** | Invoice issue date. |
| **Inv To** | The party being billed. |
| **Due** | Amount due. |
| **Due Date** | Payment deadline. |
| **Total** | Total invoice amount. |
| **Status** | Payment status (e.g. paid / unpaid / overdue). |
| **Action** | View, print, or manage the invoice. |

Use **Search** to find a specific invoice and click column headers to sort (for example by **Due Date** or **Status**).

---

## 🖨️ Printing an Invoice

1. Locate the invoice in the list.
2. Click the **Print** action on its row.
3. The invoice opens in a printable layout — print or save as PDF from your browser.

:::tip
Sort by **Status** to quickly find unpaid or overdue invoices that need follow-up.
:::
