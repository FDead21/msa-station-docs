# Print SP

The **Print SP** tool lets you search for a specific Job Order and print its **SP** (*Surat Perintah* / work order document).

Open it from the sidebar: **Report Data ➔ Print SP**.

![Print SP](/img/tms_print_sp.png)

---

## 🖨️ Printing an SP

1. Enter or select the **JO Number** (Job Order) you want to print.
2. Click the **Print** button.
3. The SP document for that job order opens in a printable view.
4. Print or save it via your browser's print dialog.

:::tip
The JO Number comes from the booking you created under [Entry Data](../awb-data/entry-data.md).
:::
