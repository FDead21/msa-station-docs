# Print Report By Date

The **Print Report By Date** tool generates a manifest report for all shipments departing on a chosen date, ready for printing.

Open it from the sidebar: **Report Data ➔ Print Report By Date**.

![Print Report By Date](/img/tms_print_report_by_date.png)

---

## 🖨️ Generating the Report

1. Select the **Departure Date** for the report.
2. Click the **Print** button.
3. The system compiles all shipments matching that departure date and opens a printable report.
4. Use your browser's print dialog to print or save the report as PDF.

:::tip
Use this at the end of each operating day to produce a consolidated manifest of everything that departed.
:::
