# Panduan Pengguna MSA Station TMS

# Selamat Datang di MSA Station TMS

**MSA Station TMS** adalah **Transport Management System** yang dioperasikan oleh **MSA Kargo**. Platform ini menyediakan pusat pengelolaan delivery order, penugasan driver, pelacakan pengiriman, dan operasional logistik last-mile.

---

## 🔐 Login Sistem

Untuk mengakses MSA Station TMS, buka peramban web Anda dan navigasikan ke alamat berikut:
`https://tmsmsa.com/msa_station/tms_login.php`

![Halaman Login TMS](/img/tms_login_screen.png)

### Langkah-Langkah Login

1. **Alamat Email:** Masukkan alamat email MSA Kargo Anda yang telah terdaftar pada kolom input email.
2. **Kata Sandi:** Ketik kata sandi akun Anda pada kolom password.
3. **Masuk:** Klik tombol **Login** untuk memverifikasi akun dan masuk ke dasbor Anda.

:::tip Masalah Akses
Jika Anda tidak dapat masuk ke sistem, hubungi administrator sistem Anda untuk memverifikasi kredensial akun atau mereset kata sandi Anda.
:::
