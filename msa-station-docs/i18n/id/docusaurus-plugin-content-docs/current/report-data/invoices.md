# Invoices (Faktur)

Modul **Invoices** menampilkan seluruh dokumen tagihan dan memungkinkan Anda meninjau, mencetak, serta melacak status pembayaran setiap faktur.

Buka melalui sidebar: **Report Data ➔ Invoices**.

![Daftar Invoices](/img/tms_invoices_main.png)

---

## 📋 Daftar Faktur

Tabel menampilkan setiap faktur dengan kolom berikut:

| Kolom | Arti |
|---|---|
| **ID** | Nomor/ID faktur. |
| **Date** | Tanggal terbit faktur. |
| **Inv To** | Pihak yang ditagih. |
| **Due** | Jumlah yang harus dibayar. |
| **Due Date** | Batas waktu pembayaran. |
| **Total** | Total nilai faktur. |
| **Status** | Status pembayaran (mis. lunas / belum lunas / jatuh tempo). |
| **Action** | Melihat, mencetak, atau mengelola faktur. |

Gunakan **Search** untuk menemukan faktur tertentu dan klik judul kolom untuk mengurutkan (misalnya berdasarkan **Due Date** atau **Status**).

---

## 🖨️ Mencetak Faktur

1. Temukan faktur di daftar.
2. Klik aksi **Print** pada barisnya.
3. Faktur akan terbuka dalam tata letak siap cetak — cetak atau simpan sebagai PDF dari peramban Anda.

:::tip
Urutkan berdasarkan **Status** untuk dengan cepat menemukan faktur yang belum lunas atau jatuh tempo yang perlu ditindaklanjuti.
:::
