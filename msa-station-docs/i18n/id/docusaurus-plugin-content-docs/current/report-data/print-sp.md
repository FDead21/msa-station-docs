# Print SP

Alat **Print SP** memungkinkan Anda mencari Job Order tertentu dan mencetak dokumen **SP** (*Surat Perintah*) miliknya.

Buka melalui sidebar: **Report Data ➔ Print SP**.

![Print SP](/img/tms_print_sp.png)

---

## 🖨️ Mencetak SP

1. Masukkan atau pilih **JO Number** (Job Order) yang ingin dicetak.
2. Klik tombol **Print**.
3. Dokumen SP untuk job order tersebut akan terbuka dalam tampilan yang dapat dicetak.
4. Cetak atau simpan melalui dialog cetak peramban Anda.

:::tip
JO Number berasal dari booking yang Anda buat di [Entry Data](../awb-data/entry-data.md).
:::
