# Print Report By Date

Alat **Print Report By Date** menghasilkan laporan manifest untuk seluruh pengiriman yang berangkat pada tanggal tertentu, siap untuk dicetak.

Buka melalui sidebar: **Report Data ➔ Print Report By Date**.

![Print Report By Date](/img/tms_print_report_by_date.png)

---

## 🖨️ Menghasilkan Laporan

1. Pilih **Departure Date** untuk laporan.
2. Klik tombol **Print**.
3. Sistem mengumpulkan seluruh pengiriman yang cocok dengan tanggal keberangkatan tersebut dan membuka laporan yang dapat dicetak.
4. Gunakan dialog cetak peramban Anda untuk mencetak atau menyimpan laporan sebagai PDF.

:::tip
Gunakan ini di akhir setiap hari operasi untuk menghasilkan manifest gabungan dari semua yang berangkat.
:::
