# Live Tracking

Modul **Live Tracking** menampilkan lokasi pengiriman dan driver Anda secara real-time pada peta interaktif.

Buka melalui sidebar: **Tracking ➔ Live Tracking**.

![Peta Live Tracking](/img/tms_live_tracking.png)

---

## 🗺️ Menggunakan Peta

Halaman menampilkan **peta** interaktif dengan penanda (marker) yang mewakili pengiriman/driver aktif.

1. Peta dimuat dengan titik tengah pada area operasi aktif Anda.
2. Setiap **marker** mewakili driver atau pengiriman yang sedang dalam perjalanan.
3. **Klik marker** untuk melihat detail pengiriman tersebut (seperti referensi booking dan statusnya).
4. **Perbesar dan geser** peta untuk fokus pada wilayah atau rute tertentu.

:::tip
Posisi langsung bergantung pada aplikasi driver yang mengirim pembaruan lokasi. Jika sebuah marker tampak usang, perangkat driver mungkin sedang offline atau belum melakukan sinkronisasi.
:::

:::info
Status pelacakan digerakkan oleh pembaruan yang dicatat di [Booking Driver](../driver/booking-driver.md) dan layar [Update Status](../report-data/update-status.md).
:::
